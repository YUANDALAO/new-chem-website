## ⚙️ 自定义配置

### 调整渲染性能

在 `chemLib.md` 中找到：

```javascript
const CONFIG = {
  batchSize: 20,    // 每批数量：10-50
  renderDelay: 50   // 延迟(ms)：0-200
};
```

**建议设置：**
- 少于50个分子：`batchSize: 50, renderDelay: 0`
- 50-200个分子：`batchSize: 20, renderDelay: 50` ⭐ 当前
- 多于200个分子：启用懒加载（见优化指南）

### 更改颜色主题

全局搜索并替换：
- `#667eea` → 你的主色
- `#764ba2` → 你的辅色
